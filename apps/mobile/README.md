# ReparaAI Mobile

Flutter Android app with offline ONNX inference, a bilingual repair catalog, and a local SQLite journal. The repository root contains [installation instructions](../../README.md) and the [Android test procedure](../../docs/TESTING.md).

The assets include the trained tiled hole detector and a configuration with its model ID, SHA-256, threshold, grid, inference stride and source dataset revision. The procedure catalog uses stable IDs and cites the supporting technical guides.
